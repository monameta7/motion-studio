# app/ui

Responsibility: the Persian right-to-left screens (React + Vite), served by the local server (docs/11). Built in Phase 4.

- `npm run ui:build` builds into `app/ui/dist`, which `npm start` serves on http://localhost:4600.
- `npm run ui:dev` runs Vite with hot reload on http://localhost:5173 and forwards `/api` to the server (start `npm start` first).
