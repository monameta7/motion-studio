# Motion Studio

برنامه‌ای که روی کامپیوتر خودت اجرا می‌شود و از یک موضوع، یک ریلز موشن‌گرافیک فارسی با صدای گوینده و برند خودت می‌سازد.

## چه چیزهایی لازم داری

- ویندوز ۱۰ یا ۱۱ و اینترنت.
- حدود ۶ گیگابایت جای خالی.
- اشتراک Claude (پلن Pro یا Max). برنامه با کلید API کار نمی‌کند.
- یک کلید Gemini برای صدا (رایگان، از aistudio.google.com). برنامه در اولین اجرا آن را از تو می‌پرسد.

## نصب

۱. منوی Start را باز کن، بنویس `PowerShell` و آن را باز کن.

۲. این خط را کپی کن، در پنجره‌ی PowerShell بچسبان و Enter بزن:

<div dir="ltr">

```powershell
irm https://raw.githubusercontent.com/monameta7/motion-studio/main/scripts/install-windows.ps1 | iex
```

</div>

۳. صبر کن تا کار تمام شود (بسته به سرعت اینترنت، ۱۰ تا ۳۰ دقیقه). اگر ویندوز برای نصب اجازه خواست، «Yes» را بزن.

۴. در پایان، برنامه خودش در مرورگر باز می‌شود و راهنمای شروع را نشان می‌دهد. آن‌جا با حساب Claude خودت وارد شو و کلید Gemini را بده.

اگر وسط کار خطایی دیدی، همان خط را دوباره اجرا کن. چیزهایی که نصب شده‌اند دوباره نصب نمی‌شوند.

## باز کردن برنامه

روی میان‌بر «Motion Studio» روی دسکتاپ دوبار کلیک کن. برنامه در مرورگر در نشانی `http://localhost:4600` باز می‌شود.

## به‌روزرسانی

در پوشه‌ی برنامه (`motion-studio` در پوشه‌ی کاربری‌ات) به پوشه‌ی `scripts` برو و روی `update-windows.cmd` دوبار کلیک کن.

به‌روزرسانی به این پوشه‌های تو دست نمی‌زند: `brand` (برندهایت)، `jobs` (فیلم‌هایت)، `refs` (کتابخانه‌ی مرجع)، `data` (تنظیمات و کلیدها).

## چه چیزی از کامپیوتر تو بیرون می‌رود

- متن و فایل‌هایی که Claude برای ساخت فیلم می‌خواند، به Anthropic می‌رود (با حساب خودت).
- متن گوینده به Gemini می‌رود (با کلید خودت).
- فیلم نهایی، صدا و بایگانی روی کامپیوتر خودت می‌ماند.
