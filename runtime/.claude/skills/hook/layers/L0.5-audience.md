## 🧠 Layer 0.5 — تحلیل مخاطب

**چرا مهم است:** هوک قوی از شناخت یک انگیزه‌ی واقعی مخاطب می‌آید: درد، خواسته، کنجکاوی، ترس واقعی، موقعیت یا هدف. درد پنهان یکی از منابع هوک است، نه تنها منبع آن.

اگر اطلاعات کافی نداری، **استنباط کن و با برچسب `[فرض]` علامت بزن** — نپرس مگر TOPIC واقعاً مبهم باشد.

| بُعد | سؤال کلیدی |
|---|---|
| **مخاطب دقیق** | دقیقاً چه کسی؟ (سن، نقش، موقعیت — نه «همه») |
| **سطح آشنایی و زبان** | مخاطب چه چیزهایی را از قبل می‌داند و کدام واژه‌ها برایش طبیعی است؟ پیش‌فرض محتوای عمومی: فهم در اولین شنیدن. |
| **درد سطحی** | چه چیزی را خودش می‌گوید که مشکلش است؟ |
| **درد پنهان** | چه چیزی واقعاً اذیتش می‌کند ولی نمی‌گوید یا نمی‌داند؟ |
| **خواسته سطحی** | چه چیزی را ظاهراً می‌خواهد؟ |
| **خواسته عمیق** | پشت آن خواسته، دنبال چه حسی/جایگاهی است؟ |
| **ممنوعه‌ها** | چه حرف‌هایی را آن‌قدر شنیده که دیگر اثر ندارد؟ |
| **نقطه کور** | چه چیزی را نمی‌فهمد یا اشتباه می‌فهمد؟ |
| **حس هدف** (ف۱) | بعد از دیدن، چه حسی باید داشته باشد؟ مفید · مهم · آرام · جاماندن واقعی |
| **واژگان مخاطب** (ه۱) | این مخاطب مشکلش را با چه کلمه‌هایی می‌گوید و جستجو می‌کند؟ (۳ تا ۶ عبارت از زبان خودش، نه زبان متخصص) |

```
مخاطب دقیق: ...
سطح آشنایی و زبان: ...
درد سطحی: ...
درد پنهان: ...          ← یکی از منابع مهم زاویه و هوک
خواسته سطحی: ...
خواسته عمیق: ...
ممنوعه‌ها (نگو): ...     ← این جمله‌ها را در هوک و کپشن استفاده نکن
نقطه کور: ...           ← یکی از منابع ارزش آموزشی
حس هدف: ...             ← یکی از چهار حس ف۱ (SKILL.md)؛ ترس ساختگی ممنوع
واژگان مخاطب: ...       ← منبع کلیدواژه‌ی کپشن، هشتگ و متن روی صفحه (ه۱، ه۲، ه۴)
```

**قوانین سخت‌گیرانه:**
1. **درد پنهان ≠ درد سطحی.** سطحی: «وقت ندارم محتوا بسازم» / پنهان: «می‌ترسم بسازم و کسی نبیند، پس تعللش می‌کنم»
2. **ممنوعه‌ها باید مشخص باشند.** «کلیشه‌ها» ❌ / «"محتوا پادشاه است"، "روزی یک پست بذار"» ✅
3. **واژگان مخاطب از زبان خودش:** «کابل استاندارد» یا «سیم ارزون که آتیش نگیره» ✅ / «سطح مقطع اسمی» ❌ (این واژه‌ی متخصص است). اگر داده‌ی جستجو یا کامنت در دسترس است، از همان؛ وگرنه `[فرض]`.
4. برای مخاطب عمومی، واژه‌های روزمره و مثال قابل لمس را انتخاب کن؛ زبان تخصصی فقط وقتی مجاز است که مخاطب آن را بشناسد یا همان‌جا ساده توضیح داده شود.
5. مخاطب «همه» نیست. «صاحبان کسب‌وکار» خیلی کلی است — بشکافش.
