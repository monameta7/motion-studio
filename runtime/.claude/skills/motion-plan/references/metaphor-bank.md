# Metaphor bank

Abstract idea → visual behaviour → suitable component and transition. A starting vocabulary, not a menu to copy. A better metaphor in the same spirit wins. Test every metaphor: readable with the sound off, not a cliché, consistent with the style lock.

| Idea | Visual behaviour | Component | Transition it suggests |
|---|---|---|---|
| Growth | the hero actor physically expands, in proportion to the number | stat, diagram | camera follows the growth, then travels into it |
| Decline, loss | an object shrinks, drains or loses parts | stat, compare | pull out to reveal the empty space |
| Competition | two paths or objects race toward one point | compare | the winner carries into the next scene |
| Complexity, chaos | a simple structure gains links until it tangles | diagram | one node is pulled out of the tangle (match-shape) |
| Simplification | the tangle collapses into one clean line or shape | diagram | morph into the solution's hero form |
| Failure, risk | a path hits a wall; a system cracks at one point | diagram, custom | push into the crack |
| Opportunity | a closed shape opens; a gate slides aside | custom | travel through the opening |
| Decision | the character reaches a fork; options light up one by one | character, compare | camera takes the chosen branch |
| Automation | repeated manual actions (the character's hand) merge into one flowing line | character → diagram | the hand's motion becomes the line (carry) |
| Speed, time saved | a long timeline folds or compresses | diagram | the folded timeline becomes the next frame |
| Time, process | a timeline moves through the world in reading direction | diagram, list | track along it |
| Information overload | a calm stream grows dense and fast | custom | freeze, then one item is pulled forward |
| Focus, insight | everything blurs or dims except one element, which scales up | title, stat | needle-zoom into it |
| Connection, network | dots link one by one into a web | diagram | travel along one link |
| Trust, proof | a claim card receives a seal, check or source chip that locks into place | quote, stat | the seal carries into the CTA |
| Cost, waste | coins or units leak from a container, counted | stat | the container empties and becomes the next frame |
| Before and after | split frame; the "after" side wipes over the "before" in reading direction | compare | wipe |
| Scale (A is n× B) | two objects; one grows to exactly n× the other | compare | travel through the larger one |
| Steps (n steps) | n nodes build themselves; the character or hero moves through them | list, diagram | the last node becomes the next scene |
| Customer journey | a path with stations; friction points visibly slow the hero | diagram, character | track along the path |

Avoid literal stock clichés: handshakes for partnership, light bulbs for ideas, rockets for growth, gears for systems, unless the style lock or the brand explicitly uses them.
